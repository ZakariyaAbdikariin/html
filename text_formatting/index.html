Web Development Terminologies

Web Development Terminologies

HTML
HyperText Markup Language used to structure content on the web.
CSS
Cascading Style Sheets used to style and layout web pages.
JavaScript
A programming language that adds interactivity to websites.
Semantic HTML
HTML elements that clearly describe their meaning, like header and article.
Element
A complete HTML structure consisting of a tag and content.
Attribute
Provides additional information about an HTML element.
DOM
Document Object Model representing the structure of a web page.
Responsive Design
Design approach that adapts layouts to different screen sizes.
Viewport
The visible area of a web page on a device.
Accessibility (a11y)
Making websites usable for people with disabilities.
SEO
Search Engine Optimization to improve website visibility.
Form
An HTML element used to collect user input.
Input Type
Defines the type of data an input field accepts.
Anchor
An HTML element used to create hyperlinks.
Media Query
A CSS technique for applying styles based on device characteristics.
Box Model
Concept describing margin, border, padding, and content.
API
Application Programming Interface for communication between systems.
Client-Side
Operations that run in the user's browser.
Server-Side
Operations that run on the web server.
Version Control
A system for tracking changes in code, such as Git.
